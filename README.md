## 🎮 Sobre o Jogo

**Sombras da Guerra: O Enigma Perdido** é um jogo 2D de aventura e quebra-cabeça com uma estética pixel art. O jogador assume o papel de um soldado infiltrado em território inimigo que descobre uma série de pistas enigmáticas deixadas para trás por uma civilização antiga.

A sua missão é decifrar esses enigmas para encontrar um artefato perdido que tem o poder de dar um fim à guerra. A jornada testará sua lógica, percepção e coragem em meio aos perigos de um mundo em conflito.

---

## ✨ Funcionalidades

- 📜 **Narrativa Envolvente:** Uma história profunda que se desenrola a cada enigma resolvido.
- 🧠 **Quebra-cabeças Desafiadores:** Puzzles que exigem lógica, observação e criatividade para serem superados.
- 🌍 **Exploração de Cenários:** Explore ambientes ricos em detalhes, desde trincheiras sombrias a ruínas antigas e misteriosas.
- 🎨 **Estilo Pixel Art:** Uma estética nostálgica que dá vida ao mundo do jogo, inspirada em clássicos do gênero.

## 🛠️ Tecnologias Utilizadas

Este projeto está sendo desenvolvido com as seguintes tecnologias:

- **Game Engine:** [Godot Engine](https://godotengine.org/) (Versão 4.x com suporte a .NET recomendada)
- **Linguagem:** C#
- **Arte:** [Aseprite](https://www.aseprite.org/) / [Photoshop](https://www.adobe.com/br/products/photoshop.html) (para a criação dos assets em pixel art)
- **Plugins:**
    - [Dialogue Manager](https://github.com/nathanhoad/godot_dialogue_manager)
    - [Phantom Camera](https://github.com/ramaskrik/phantom-camera)

## 🚀 Como Começar

Para clonar e rodar este projeto em sua máquina local, siga os passos abaixo.

### Pré-requisitos

- [Git](https://git-scm.com/)
- [Godot Engine (versão 4.x com suporte a .NET)](https://godotengine.org/download/)
- [.NET SDK](https://dotnet.microsoft.com/download) (geralmente incluído na versão .NET do Godot)

### Instalação

1.  Clone o repositório:
    ```sh
    git clone https://github.com/seu-usuario/sombras-da-guerra--o-enigma-perdido.git
    ```
2.  Abra o Godot Engine. Na janela do Gerenciador de Projetos, clique em "Importar".
3.  Navegue até a pasta onde você clonou o repositório e selecione o arquivo `project.godot`.
4.  O projeto aparecerá na sua lista. Selecione-o e clique em "Editar".
5.  A cena principal do jogo deve ser executada ao pressionar o botão "Play" (F5).

## 📂 Estrutura do Repositório

A estrutura de pastas do projeto segue o padrão do Godot:

- `/`: A raiz do projeto contém o arquivo `project.godot` e as pastas principais.
- `/addons`: Contém plugins de terceiros, como o Dialogue Manager e o Phantom Camera.
- `/Assets`: Contém os recursos do jogo (scripts, sprites, cenas, etc.).
- `project.godot`: O arquivo principal que define o projeto para a engine.
